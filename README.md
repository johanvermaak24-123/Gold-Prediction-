# Gold Oracle — XAUUSD

Hierdie pakket bevat die volledige selfstandige bronlêer vir die Gold Oracle-forecaster. Die app gebruik geen npm-pakkette nie; sy HTML, ontwerp en JavaScript is in **index.html**.

## Laai dit na jou GitHub-repo op vanaf iPhone

1. Laai **Gold-Oracle-GitHub-Source.zip** af en tik daarop in die Files-app om dit uit te pak.
2. Skep ’n nuwe repo op GitHub, byvoorbeeld **gold-oracle**. Hou dit **Private** terwyl jy toets.
3. Maak die repo in Safari oop en kies **Add file → Upload files**.
4. Laai die uitgepakte **index.html** en hierdie **README.md** op en kies **Commit changes**.

As jy net ’n rugsteunkopie wil hou, kan jy die ZIP self as een lêer na ’n repo oplaai. Om die bronkode maklik te lees of later te wysig, laai die twee uitgepakte lêers op.

## Belangrike opmerking

Die GitHub-kopie is ’n rugsteun. Dit sinchroniseer nie vanself met die afsonderlik ontplooide Gold Oracle-Site nie. Die app se openbare XAU/USD-toevoer is aanduidend; bevestig pryse en uitvoering op jou eie brokerplatform.
